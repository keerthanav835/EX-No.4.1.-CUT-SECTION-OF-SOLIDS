EX No.4.1. CUT SECTION OF SOLIDS
 

 AIM:
To create the solid model from given drawing and section the solid model

 REQUIREMENTS:
 
1. Autodesk fusion 360
2. Windows 10
3.16 GB of RAM (integrated graphics recommend 1 GB or more)
4. 2.5 Mbps or faster download; 500 Kbps or faster upload 

 PROCEDURE:
 
1. Open Autodesk Fusion 360, select New Design, and create a new sketch on the XY plane. Draw the base profile using a horizontal centre line and two end circles. Set the overall length to 100 mm and width to approximately 50 mm.

2. Use the Circle Tool to draw the two end circles and apply R15 mm radius to both ends. Position them symmetrically and connect the circles using tangent lines.

3. Use the Trim Tool (T) to remove the unwanted portions of the circles and lines. Complete the outer base profile and ensure that the sketch is fully closed.

4. Apply the Dimension Tool (D) to set the required dimensions. Maintain the overall length of 100 mm, width of 50 mm, and end radius of R15 mm.

5. Finish the sketch and use the Extrude Tool (E) to extrude the base profile by 12 mm to create the bottom plate.

6. Select the top face of the base and create a new sketch. Draw a concentric circle at the centre with an outer diameter of Ø30 mm and an inner diameter of Ø20 mm.

7. Finish the sketch and use the Extrude Tool to create the raised cylindrical portion. Set its height to 26 mm above the base.

8. On the top face, use the Hole Tool or Circle Tool to create two holes of Ø12 mm on both sides of the central boss. Position them symmetrically and apply the Through All option.

9. Apply the required circular and cylindrical details using the Trim Tool, Fillet Tool, and Radius/Dimension Tool wherever necessary. Check the concentric circles and hole positions.

10. Finally, inspect the completed model in Isometric View. Verify the overall dimensions (100 mm × 50 mm), central diameters (Ø30 mm and Ø20 mm), side holes (Ø12 mm), and height (38 mm). Save the completed design.
